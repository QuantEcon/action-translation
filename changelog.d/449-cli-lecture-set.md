### Changed

- **`translate init` and the CLI's bulk modes take their lectures from the lecture set: the documents `_toc.yml` lists, then the `.md` files they include** (#449, #385). `status`, `forward`, `backward`, `headingmap` and `doctor` listed only the `.md` files at the top level of the docs folder, so a lecture in a subfolder, such as the GPU notice `_admonition/gpu.md` that lectures pull in with `{include}`, was never listed, resynced, analysed, given a heading-map or a state file, or counted by `doctor`, while a `README.md` was. `init` took the ToC's entries alone, so it neither translated nor copied `_admonition/gpu.md`, and a fresh edition's lectures included a file it lacked. Each command now reads each repository's lecture set, as ruled on #449: the source's, and the edition's own from its mirrored `_toc.yml`, whose entries without a file (lectures a partial edition has not translated) are not lectures. Files are named by their path in the docs folder (`_admonition/gpu.md`), and `--exclude` matches that path. `init` translates an included file like any lecture, after the documents, with its state file, and `init -f _admonition/gpu.md` translates it alone; `-f` still refuses a file outside the set, by name. `-f` takes the lecture at the path it names, else the one with that file name in any folder (`-f gpu.md`), else the one whose path contains the name, and refuses a name that matches more than one, naming them, where it used to translate the first. `doctor` gains a `Lecture set` check, and `backward` writes a subfolder lecture's report, and its resume sidecar, at the lecture's path, where `review` finds it.
- **A bulk run stops when a docs folder has no `_toc.yml`** (#449, ruling 9). Without a ToC there is no lecture set, so `status`, `forward`, `backward` and `headingmap` exit 1 naming the repository and its folder, as `init` already did, and `doctor` fails its `Lecture set` check and skips the checks that run on it. A bulk mode's `-f <file>` names one file and skips discovery, so it works on any folder. A docs folder that does not exist stops the run the same way, where `status` used to report no files and exit 0. `init` now refuses a `_toc.yml` with no `root`, or with a `format` other than `jb-book` or `jb-article`, which it used to read; Jupyter Book needs both, and the reader refuses such a ToC rather than read it as an empty book.
- **`translate status` lists a lecture taken out of the ToC but kept as `UNLISTED`** (#449, ruling 4). An edition `.md` that neither lecture set holds but that has a state file is no longer synced, so `status` names it, in the table and in `--json` (`summary.unlisted`), rather than let it go stale unseen. It is only reported: `--write-state` leaves its state file as it is, `--check-sync` does not triage it and `forward` does not resync it. A state file of one that cannot be read is named in its line, since no other check reads it. A `.md` with no state file, such as a `README.md`, is not listed.

### Fixed

- **`translate init` no longer fails on a ToC entry that has no `.md` behind it** (#449). It appended `.md` to every entry and translated what it named, so a `root: index` with no `index.md`, as in the test repositories, failed the run with exit 1, and a notebook entry `foo.ipynb` became a missing `foo.ipynb.md`. Such an entry is now named on the console and not translated: one with no file at all as `Not translated: … with no .md file behind it`, and a notebook, which the run copies with the other non-Markdown files, as backed by a file that is not Markdown. A `jb-article`'s root-level `sections:` are read too; `init` used to miss them.
- **`--exclude "troubleshoot*"` matches** (#449). Two tutorials showed a pattern with a trailing `*`, but `--exclude` matched only an exact name or a leading `*`, so the example excluded nothing. A `*` at either end of a pattern now matches any text there: `*.yml`, `troubleshoot*`, `_admonition/*`, `*draft*`.
