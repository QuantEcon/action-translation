### Fixed

- **`translate init` no longer overwrites the edition's own files** (#134). `-f` narrowed the translation, not the rest of the run: every run copied each non-Markdown file in the source docs folder over the edition's copy, `_toc.yml`, `_config.yml` and localised figures included, rewrote `.translate/config.yml` from its flags, dropping its comments, and wrote `TRANSLATION-REPORT.md` at the edition's root. On the lecture-at-a-time route for partial editions (#344) that came with every round, and the tutorials had the operator restore the edition's copies and delete the report each time. `init` now copies only the files the edition does not have, and prints how many it copied and kept; a dry run prints the same counts, where it used to count every file, symbolic links included. It writes `.translate/config.yml` only when the edition has none: a config whose `source-language`, `target-language` and `docs-folder` match the flags is left byte for byte, and one that differs stops the run before any model call, dry run included, naming each key with both values (`lectures/` and `./lectures` match `lectures`; an empty config has no keys, so each is named). With `-f` it writes no `TRANSLATION-REPORT.md`, and prints a failed lecture's whole error on stderr, since the failure line keeps only 200 characters; `--report-json` still records the run. A bulk run into an existing edition keeps the edition's copies too, so a build file the source has changed since is not refreshed: copy it by hand. The restore step is gone from the tutorials.
