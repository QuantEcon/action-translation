### Changed

- **Sync takes its lectures from the source's lecture set: the documents `_toc.yml` lists and the `.md` files they include** (#449). Sync took every `.md` under `docs-folder`, subfolders included, so a changed draft, a `README.md` or an entry commented out of the ToC was translated into the edition. It now reads the source's `_toc.yml` at the commit being synced, with one tree read for the folder's file list, and syncs a changed or renamed `.md` only when the ToC lists it or a lecture it lists includes it with `{include}`, as lectures include `_admonition/gpu.md`. A file outside the set is not translated. The PR body lists it under **Files Outside the Lecture Set**, and so does the job summary, which a `sync-scope: all` run now writes whenever it has something to list. A source PR that changes only such files passes with no PR. Under `sync-scope: existing` the lecture set is checked first, so such a file is never checked for a state file. Removals are unchanged: a removed `.md` is deleted from the edition whether or not the ToC listed it.
  - **A lecture set that cannot be read fails the run.** A source `_toc.yml` that is missing, cannot be parsed or has a layout the action does not read, and a file list that GitHub truncated, each hold the whole sync, with a failure issue, which names any lecture the held PR removed or renamed, to delete from the edition by hand. The file list and the ToC are retried twice on a 5xx or a rate limit first. The run never falls back to the folder. A lecture that cannot be read while the run looks for a changed file's includer is an error for that file alone, and the other files still sync.
  - **A lecture renamed to a path outside the set is not carried.** The edition keeps it, and its state file, under the old name, and the PR body lists the rename.
  - **A `_toc.yml` change is compared with the ToC before it.** A lecture the PR takes out of the ToC but keeps in the folder stops syncing: the edition keeps its translation, and the PR body lists it under **Lectures Taken Out of the ToC**. A lecture the PR adds without changing it is listed under **ToC Entries With Nothing Delivered**, with its catch-up: `translate status -f` and `translate forward -f` when the edition has its state file, `translate init -f` when it has none.
  - **An include the edition lacks** is listed under **Included Files the Edition Lacks**, for each lecture the PR delivers, with `translate init -f <file>` as the catch-up. Sync translates none of these files, and none is in the PR's metadata `files`.
