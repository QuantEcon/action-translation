### Fixed

- **A change to an included fragment with no title, such as `_admonition/gpu.md`, now updates the edition's copy instead of failing the sync** (#449). Sync updates an existing translation section by section, and that needs a `# title` to split on. A file without one failed with "Document must have a # title heading", and the run opened a failure issue, in every edition that holds the file: lecture-python-programming's fr, zh-cn and fa editions, and lecture-python.zh-cn. Such a file is now updated whole, from the current English and the edition's translation, with the prompt `translate forward` uses for a whole-file resync. A renamed one is updated the same way. A file with a title is still updated section by section, and a new fragment was already translated whole.
