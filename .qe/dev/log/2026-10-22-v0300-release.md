## Traps met

- macOS `/bin/bash` is 3.2: no `declare -A`.
- zsh reads `$VAR:path` as a history modifier: write `${VAR}:path`.
- `gh … --jq .body` adds a trailing newline; a body compare across two fetch methods is off by it.
- `git fetch --tags` fails when the floating tags have moved remotely; fetch without `--tags`.
- A guard that prints a mismatch but exits 0 does not stop a `&&` chain: make it exit non-zero.
- A bare `#N` in a comment on this repository links here, even for a harness PR: write
  `owner/repo#N`.
