# 2026-10-20 — the Claude 5.5 evaluation, pre-registered (PR #395, stacked on #394)

**Trigger**: the second half of @mmcky's request: validate the 5.5 upgrade with an evaluation
project before the default moves (log `2026-10-19-claude-5-5-engine` has the engine half).

**PR #395** builds the instrument and the protocol. It does not run them: the session had no
Anthropic key.
- **Telemetry**: `translate init --report-json` gives each lecture's outcome and failure class
  (`classifyFailure`), with usage, thinking tokens, cost, served models and retries.
  `src/model-pricing.ts` is the one price table.
- **Release instrument**: `rate-check.sh` classifies every draw when the engine reports, keeps
  step 4b's legacy rule for older engines, and drops infra draws from both counts. It can now run
  real lectures and resume safely.
- **Experiment**: `experiments/claude-5-5-upgrade/` holds the protocol, a pinned corpus of 246
  files, the driver, the rules engine, the R1 check and the advisory judge.

**The protocol changed before any draw.** Two critics went over the draft spec, and the
implementers rechecked each statistical claim by exact enumeration or simulation:
- **R2's per-cell ≤ 1-in-12 clause**: it would have blocked a model exactly as good as Sonnet 5
  about two times in three, given the measured 4–6% fence-wrap rate (#203/#363).
- **R2's superiority test** ("p ≥ 0.05 passes"): it let a doubled failure rate through about two
  times in three. R2 is now a pooled non-inferiority bound at 6.5 points, plus 4b's same-day
  control.
- **The draft A/A** ran both arms on the new SDK. R1 is now a deterministic $0 comparison against
  v0.29.5 on its own dependencies.
- **R3** gained a mandatory sweep of all 234 production-repository lectures.
- **The ml edition** stays on Sonnet 5 until a native-review round of a Sonnet 5.5 draft.

**Verification**: 1,897 tests across 75 suites.
- An offline end-to-end run at $0 drove the real rate-check, the built CLI and a fake API.
- An adversarial review confirmed 19 defects, all fixed with tests that were reverse-mutated to
  show they catch the defect. The two high ones:
  - from a symlinked checkout path, the gate exited 0 having drawn nothing;
  - Ctrl-C left billed draws running with no spend cap.

**Billed runs owed to @mmcky**:
- **Stage 0a** (free): build a v0.29.5 baseline with its own `npm ci` and run `engine-aa.mjs`.
- **Stages 1–4**: about $268 typical, stopped at 1.5× each invocation's estimate.
- **One-draw smoke** of `rate-check --ref v0.29.5 --ref-deps own`.
- **Stage 5**: the harness at the flip branch, which needs the `workflow` scope.
