## The rollout

The plan makes `translate doctor --require-state` a required CI check in the five editions
that sync. That meets condition 3 for retiring `sync-scope`. The record is
`D-2026-11-16-require-state-rollout`. A Fable review of the plan, checked against the
repository and GitHub, made four fixes:

- **What the state file records.** `status --write-state` records a file's last English
  commit, not the source's HEAD. A shallow source clone makes it refuse.
- **The config.** It always rewrites `.translate/config.yml`, bumping `tool-version`, so the
  edition PRs restore that file.
- **A workflow of its own.** All five editions run `ci.yml` on `pull_request` only, so the
  check needs its own workflow to run on pushes to `main`.
- **Rulesets.** None of the five has classic branch protection. lecture-intro.zh-cn and
  lecture-python.zh-cn have rulesets without a required check; the other three have none.

Matt chose a laptop session for the edition PRs and a session with an admin token for the
rulesets. Step 1 is open: QuantEcon/lecture-python-programming.fr#108,
QuantEcon/lecture-python-programming.zh-cn#149 and QuantEcon/lecture-python.zh-cn#321. Each adds
`_admonition/gpu.md`'s state file, recording `3e4f703` (lecture-python-programming) or `1f6b3fa`
(lecture-python.myst). The three translations already carried the English's January 2026
